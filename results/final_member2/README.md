# Final Member 2 Package

This package consolidates the completed Member 2 AI-model work for the existing IFI district flooded-area regression baseline.

## Scope

The current experiment uses only `Population` and `Parmanent_Water` to predict `Corrected_Percent_Flooded_Area`. It is a limited district flooded-area regression baseline, not a complete flood forecasting system.

## Package contents

- `member2_final_report.md`: review-ready technical report.
- `member2_final_metrics.json`: protected baseline and selected controlled-experiment metrics.
- `member2_model_comparison.csv`: consolidated baseline and selected experiment results.
- `member2_experiment_summary.json`: reproducibility and experiment status summary.
- `member2_reproducibility.md`: verified commands, paths, and artifacts.
- `member2_limitations.md`: scientific and data limitations.
- `figures/`: copies of existing evaluation and experiment plots.

No model checkpoint is copied or modified by this package.
